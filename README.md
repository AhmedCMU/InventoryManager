# Title

InventoryManager

# Project description

building the inventory management system using phyton that allow us to view the item, add item,and remove, overall this project assist the user to manage inventory item.

# Current features

the feature that this project has is such as, view item, add item using name of the item, Category and quantity, remove items,
update the quantity of the items, search item using match key, view summary after add or remove and exit.

# Requirements

Python 3
A terminal or command prompt
A code editor such as Visual Studio Code (optional)

# project file description

inventory_manager.py — Contains the main program and inventory functions.

# iventory date format

Inventory data is stored in inventory.txt. Each line contains an item name, category, and quantity separated by vertical bars (|).
Example:
Laptop Charger|Electronics|8
Printer Paper|Office Supplies|25
